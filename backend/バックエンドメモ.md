ここがバックエンド

バックエンドに関するファイルはすべて

\backend

のしたに

## 初回セットアップ

```bash
cd backend
npm install
```

## 使えるコマンド

`backend` フォルダで実行します。ルートから実行する場合は `npm run <コマンド> --prefix backend` です。

| コマンド      | 内容                                                                 | いつ使う？               |
| ------------- | -------------------------------------------------------------------- | ------------------------ |
| `npm run dev` | nodemon でサーバーを起動する。ファイルを保存すると自動で再起動される | 開発中（ふだんはこれ）   |
| `npm start`   | `node server.js` でサーバーを起動する。自動再起動はしない            | 動作確認・本番に近い起動 |
| `npm test`    | テストを実行する（まだテストなし）                                   | PR を出す前              |

## 動作確認

`npm run dev` で起動したあと、ブラウザで次の URL を開きます。

```
http://localhost:3000/api/health
```

`{"data":{"status":"ok"}}` と表示されれば正常です。

## メモ

- ポート番号は `3000`（環境変数 `PORT` で変更可能）
- 成功時のレスポンスは `{ "data": ... }` の形式（共通仕様に従う）
- 本番は AWS（Lambda + API Gateway）の予定。この Express サーバーはローカル開発用の仮のもの
- `.env` や DB のパスワード、AWS のキーは絶対にコミットしない

## 仮サーバー（mock-server）

AWS の API ができるまで使う開発専用のサーバーです。12/20 に `backend/mock-server/` ごと削除します。

```bash
npm run dev          # ルートで実行：フロントエンド＋仮サーバーを同時に起動
npm run dev:back     # ルートで実行：フロントエンド＋本来の server.js を起動
npm run dev:mock --prefix backend   # 仮サーバーだけ起動
```

- データは `frontend/src/mocks/` から読み込み、メモリ上だけで動きます（再起動で元に戻る）
- 操作するユーザーは、リクエストヘッダー `X-Mock-User` にユーザーID（`1`〜`7`）を入れて指定します
- 特別な値：`new-student`（卒業年度が未設定の初回ログイン学生）、`ineligible`（利用対象外の拒否）
- ユーザーID `4` は無効化されたユーザーで、ログインは `ACCOUNT_INACTIVE` で拒否されます
- 実装済み：A-01、U-01、U-02、C-01〜C-07
